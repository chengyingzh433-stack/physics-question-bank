Windows 64 位 · 1.1.0-beta.3 · 2026-10-23

教师题库测试版

直接双击桌面的“教师题库测试版”，即可使用。
项目文件夹内的“打开题库测试版”快捷方式也可以打开。无需命令行，无需安装 Node.js。

两个入口，任选一个

  1. 现在就用：双击桌面“教师题库测试版”。这是已打包的独立程序，不会启动开发服务器。
  2. 安装后长期使用：打开项目中的 release → 1.1.0-beta.3，双击“教师题库-测试版-1.1.0-beta.3-安装程序.exe”。按中文向导选择安装位置，完成后从桌面或开始菜单的“教师题库”打开。

升级后请先关闭旧版本窗口，再打开桌面快捷方式，确认顶部版本号为 1.1.0-beta.3。重复双击会返回已有窗口；关闭程序窗口即可退出。

建议先这样体验

  1. 将一份或多份 PDF 从文件夹拖到“主页”，松开鼠标即可导入；也可点击“导入试卷 PDF”选择文件。导入后点击试卷卡片，按流程裁切、编号并入库；需要答案时再导入答案 PDF 并匹配。
  2. 后期处理和复查页的“章节”可以直接选用人教版（2019）高中物理六册目录，输入关键词即可查找。“章节模板 / 自定义”可以套用预设，或在指定上级目录下新建个人章节。知识点输入前几个字即可匹配、多选；没有现成条目时点击“新建并选中”。
  3. 进入“题库浏览”，新建一个题夹，例如“期末复习好题”。勾选题目后点“加入题夹”。同题可以放进多个题夹。
  4. 用试卷名、出处、章节或知识点找题，也可筛选有答案/无答案。较窄窗口通过“分类 / 筛选”按钮展开条件。
  5. 点击题图查看完整题目与答案；勾选仅表示选中，点“加入组卷篮”才会入篮。翻页保留勾选，切换筛选会清空勾选。
  6. 进入“组卷篮”，调整题序、标题和答案位置，再导出 PDF 或 PPT。

这一版包含什么

PDF 拖放导入、切题与编号、题图入库、答案匹配、预设及自定义章节、知识点搜索多选、个人题夹、组合检索、批量归类/选题、PDF/PPT 导出。章节按册、章、节组织，题库选中上级章节时会包含下级题目。扫描型 PDF 仍按题图处理。

后续阶段：文字和公式编辑、图片独立调整、题干全文搜索、Word 导出，以及整体导航整理。当前检索的是资料名称和标签，导出内容仍以题图为主。

题库保存在哪里

本机默认沿用原有题库数据。数据库位于用户目录的 AppData/Roaming/physics-question-bank/app.db；题图与原 PDF 位置可在右上角“设置”查看。删除题夹只删除归类关系，不删除原题。

免安装入口依赖项目内完整的 release/1.1.0-beta.3/win-unpacked 文件夹，请不要只移动其中的 EXE。需要换电脑时，可携带安装程序；已有题库资料需另外迁移。

测试情况

自动测试、类型检查和构建通过；已验证隔离数据下的章节模板、搜索多选、保存重开，以及实际发布 EXE 的题图显示、题夹、组卷、PDF/PPT 三种答案模式导出、PDF 渲染和重复启动。未在另一台干净 Windows 电脑进行安装验收。

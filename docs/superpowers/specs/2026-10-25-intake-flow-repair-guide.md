# beta.10 单题录入使用说明

## 从打开软件开始

1. 打开后直接看到“录入一道题”。选图片 / PDF / Word、粘贴截图或文字，或点击“直接输入文字”。也可把文件拖入录题页。旧 DOC 需先另存为 DOCX/PDF。
2. 一张图片或文字进入“校对这道题”。PDF / DOCX 先显示原稿，框选一道题后点击“继续校对与选标签”；分区组题仍支持分别加入题干、选项和配图。
3. 校对页先显示原稿与正文。点击“答案与解析”输入答案；点击“选标签”跳到本页标签区，可选题型、章节、难度、知识点及来源。
4. 图片中的字需点击“图片转文字 / 识别”使用 Doc2X。未配置 API Key 时会引导设置；每次云识别仍需确认上传。也可保留图片直接入库。输入文字/答案后自动选择可编辑内容用于 Word；需要用原图导出时可展开“Word 导出设置”调整。
5. 核对完成点击底部“保存并入库”。成功页面会提供“查看题库”“继续录下一题”和“继续修改这道题”。

## 未完成的修改

- “暂存”和 ⌘S / Ctrl+S 保存正文及标签，但待入库题仍需“保存并入库”。
- 编辑正文和标签时保存本机恢复副本；重进题目时若存在未提交修改，会提示“恢复修改”或“使用已保存版本”。恢复先回到编辑区，不自动覆盖正式题目。
- 若正式版本或标签已改变，恢复前会再次提示核对。恢复副本依赖本机浏览器存储；空间不足时会提示及时暂存。它不替代数据库备份，也不保存尚未提交的识别候选。
- 页面异常提示不再笼统保证所有未提交数据均未丢失。原稿和已保存题目与恢复副本分别保存。

## 导航

主导航：录题、我的题库、组卷篮。“更多工具”内保留整卷 PDF 裁切、题型与模板。录题页默认列出未完成草稿；已入库题到“我的题库”查看，也可勾选显示历史记录。

## 建议用户验收

- 选一张实际题图，补充文字、答案、标签并入库，查看题卡和答案预览。
- 输入未提交修改，返回再进入，确认恢复提示及内容。
- 使用实际 PDF、DOCX 框选题目进入校对；复杂 Word 排版需以原件核对。
- 配置 Doc2X 后单独验收识别、公式、配图及采用候选。此版本不增加自动上传或自动解题。
- Word 按导出设置使用内容；PDF/PPT 仍使用原图。本阶段未新增批量录题或一键 PNG 合成导出。

# 第二阶段交付：连续录题与选区取字

日期：2026-11-15。版本：1.1.0-beta.14。状态：实现、静态检查、编译及 DMG 制作完成；实际功能与使用效果待用户验收。

## 本次完成

- 同一原稿连续录题：校对页提供“保存并录下一题”“保存并结束”。下一题回到同一份原稿及原来的页码、视图缩放和滚动位置。
- 视图位置独立保存在本机数据库中，按草稿、原稿分别记录。返回草稿或重启后，从录题列表的“继续录题”恢复。位置变化不生成正文历史版本。
- 下一题共享原稿引用，不再次复制 PDF；正文、答案、组成部分、选区和识别候选全部清空。新题名称从原稿名称和连续录题序号生成，可自行修改。
- 来源、年份默认沿用；题型、章节、难度、知识点逐项勾选。新草稿显示实际继承的值，可在校对页继续修改。
- “本次连续录题”折叠列表显示已录题和当前草稿，可以回看修改已录题，之后回到未完成草稿。
- 数字 PDF 根据当前选区提取已有文字层，先展示候选，可修改或取消。采用才追加为当前部分，不替换已有正文；可跨页按顺序多次采用，并调整部分顺序。对同页同范围重复采用予以提示。
- 采用文字时保留原选区图片作对照，原图模式仍能查看选区原貌；编辑稿仅包含采用的文字，图片内配图需要另外框选添加。当前原稿、原 PDF 均保留。
- DOCX 保留明确标注的“读取 Word 整页文字”入口，进入相同候选确认流程，不将其描述为精确选区取字。

## 入口与操作

### 只想按原图连续收录

1. 打开软件 → 录题 → 选择 PDF、图片或 DOCX。
2. 在原稿上框住一道题，点击“将选区作为整道题，继续校对”。
3. 核对题目与标签，按需展开“下一题沿用标签”。
4. 点击“保存并录下一题”。保存成功后回到原稿，上一题选区清空；继续框下一题。
5. 最后一题点击“保存并结束”，查看题库或更换原稿。

### 想把数字 PDF 录成可编辑文字

1. 框选题目范围，点击“提取选区文字”。若明确切换“使用整页”，则读取当前整页文字。
2. 在“核对提取文字”窗口修改候选，特别核对公式、选项和边缘字符；点击“采用并加入当前题目”。
3. 如有配图，打开分区组题，选“题干配图”，框选图片加入。原选区对照图不会自动重复加入编辑稿。
4. 跨页题可翻页继续取字，采用次序即组题次序；在右侧上移、下移或删除部分。
5. 继续校对、选择标签，再保存并录下一题。提取和组题在本机完成，不调用云识别。

### 暂停与恢复

先把已输入文字点击“暂存”保存；已采用的选区文字及已加入的图片部分已写入草稿。返回录题列表或退出软件后，重新选择对应草稿“继续录题”。原稿位置自动恢复，未加入的选区和未采用的候选不属于已保存正文。

若本题已入库但下一题建立失败，提示明确区分两个结果；点击“继续同一原稿”重试。数据库用上一草稿的唯一接续关系保证重试返回同一下一题，正文、标签和入库状态沿用既有事务保存。新的草稿、原稿引用、继承标签及接续记录在另一事务中一起创建。

## 已知边界

- 本次是逐题连续录入，不是整卷自动分题、批量 OCR 或自动答题。
- 选区取字依赖 PDF 自带文字层。损坏编码、字体、连字、竖排、多栏、上下标和公式可能影响准确率及顺序。单个文字段内部字符位置根据字体宽度估计，因此选区边缘需人工核对；不承诺 OCR 或数学语义还原。
- 候选最多 2 万字；只提取文字，不自动分离原图内的配图或恢复公式结构。公式可在校对页手动编辑，或主动调用既有识别功能。
- DOCX 仍由本机预览生成分页，不等同于 Word 的精确版式。记录页码越界时恢复至最后有效页并提示；窗口尺寸改变时滚动位置按比例恢复。
- 单个草稿的下一题为唯一接续草稿；返回更早的已录题后继续，会打开其已有下一题。通过连续列表可直接进入当前未完成草稿。
- 未加入的选区、未采用的候选和未暂存的输入不承诺跨退出恢复。原稿位置和已保存草稿可恢复。
- Mac 包面向 Apple Silicon，最低 macOS 13；未做 Intel Mac、Windows 实机功能验收。没有 Apple Developer ID 签名与公证。

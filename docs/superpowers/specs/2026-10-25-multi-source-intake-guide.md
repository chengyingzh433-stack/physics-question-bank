# M21 录题工作台使用与用户验收

版本：Mac 1.1.0-beta.8。入口：左侧“录题工作台”→“新建录题”。本说明的清单交由用户实际验收，开发者未执行功能测试。

## 1 添加原稿

- 点击“添加图片 / PDF / Word”，可多选文件；也可拖入文件。支持 PNG、JPEG、PDF、DOCX。
- 复制截图后，在工作台按 Mac 的 ⌘V 或 Windows 的 Ctrl+V，或点击“粘贴截图或文字”。剪贴板图片成为原稿；按钮读到文字时，文字进入右侧输入框。
- 图片上可选择整图或拖动框选；PDF 和 Word 可切换页码。带文字层的 PDF、DOCX 可点击“读取本页文字到输入框”，再删除不需要的文字、分段录入。扫描 PDF 没有文字层时继续框选。
- 点击“查看原件”在文件管理器中定位保存在题库资料目录的原文件。选区是副本，不改原件。

## 2 两种录入方式混合使用

先在右侧“当前添加到”选择题干、选项、答案、解析、题干配图或答案配图。

**原稿框选：** 在左侧切换“拖动框选一部分”，拖出区域，再点击“将选区加入……”；选区类型使用右侧当前选择。选项可填写 A/B/C/D，添加后字母递增。题目跨页时分别加入多个题干部分；配图单独框选后选“题干配图”。如果选区已包含选项字母，可以清空选项标记，避免重复添加；纯文字选项仍需要填写标记。

**分区输入：** 在右侧粘贴题干或选项文字，点“加入组题”。复制图片后点“粘贴图片到此部分”，图片会同时作为原稿留存和当前部分的独立配图。已上传的图片也可在左侧选整图后加入相应部分。两种方式可以交替。

组成部分会列在下方，可修改文字、改变角色或选项标记，上移、下移、移除。移除只从当前组合去掉，保留原稿与图片资源。题干与选项、题干配图按各自出现顺序汇成题干；答案、解析与答案配图按出现顺序汇成答案。

添加、排序、移除会保存当前组合。修改名称或已有部分的文字后，点“保存”，或按 ⌘S / Ctrl+S。**输入框中尚未点“加入组题”的文字还不属于组合，应先加入再保存。** 页面会提示未保存修改，退出前请确认。

## 3 预览、识别与校对

1. 点“生成校对预览”，查看题干、答案合成图是否完整、顺序正确。
2. 勾选确认，进入“识别与校对”。此动作只在本机保存快照，不上传文件。
3. 手工输入的文字和各部分图片已进入可编辑稿；可直接编辑、插入公式、调整图片，也可使用下方 Doc2X 云识别。
4. 使用 Doc2X 时，按已有流程启用服务、配置自己的 API Key；选择题干或答案，预览本次上传的副本，确认后才发起识别。题干与答案分开提交，分别消耗服务额度。原 PDF / Word 不会整份上传。
5. 对照原图修正识别候选，处理表格、缺图、公式等提示，采用并保存。采用识别内容后，题干和答案中存在识别来源的部分要分别勾选“我已对照原图完成当前部分的校对”并保存。
6. 在顶部勾选整题核对确认，点“确认入库”。此后在“题库浏览”中可以加标签、加入题夹、加入组卷篮并导出 Word。

Doc2X 用于识别文字、公式和图片结构，不保证物理答案正确。无 API Key 或不想使用云服务时，可以全程手工完成。Key 申请见 [既有说明](2026-10-25-in-app-update-guide.md)。

## 4 中途保存与下一题

- 离开后从录题工作台打开“组题草稿”继续；已生成快照的显示“待校对”，可直接继续校对。
- 原稿可以反复使用。“沿用原稿，录下一题”建立空白组合，保留来源文件关联。
- 生成快照后原组题组成部分冻结。需要重选区域或改变组合时，点击“复制并重新组题”；旧快照、编辑历史、识别记录均保留，新稿需要重新校对并入库。
- “归档草稿”收起尚未生成快照的草稿，不删除资料；在工作台勾选“显示已归档草稿”可恢复。
- 此版本保留所有来源和移除的图片副本，不自动清理磁盘资源。

## 5 格式与容量边界

| 内容 | 当前支持及限制 |
| --- | --- |
| 截图 / 图片 | PNG、JPEG；单文件 20 MiB，单边最多 12000 像素、总像素最多 4000 万；其他格式先另存 PNG/JPEG |
| PDF | 单文件 100 MiB；本机逐页预览，选择所需页和区域；加密文件需先自行解密 |
| Word | DOCX 单文件 30 MiB；正文 XML 最多 8 MiB、解压总量最多 100 MiB、最多 300 个预览页；不支持 DOC、宏、ActiveX 和加密文档 |
| Word 保真度 | 支持常见文字、表格、图片与现代公式预览；复杂浮动对象、旧公式、特殊字体和分页可能不同；外链图片、嵌入对象、非 PNG/JPEG 图像可能跳过或提示改用 PDF |
| 草稿 | 每稿最多 40 个原稿、80 个组成部分；单部分文字最多 2 万字、整题文字最多 8 万字 |
| 合成快照 | 每部分（题干/答案）单边最多 12000 像素、生成文件最多 20 MiB；超过尺寸会提示拆题，不静默截断 |
| Doc2X | 沿用 7 MiB 上传限制，可缩小上传副本；由用户逐次确认，真实额度和金额以账户平台为准 |
| 平台 | 此轮提供 Apple Silicon Mac DMG；代码保持 Windows 路径、快捷键与文件选择兼容，未制作或验收新的 Windows 包 |

## 6 用户自测清单

以下均为待用户执行，不表示已经通过。

- [ ] 图片选择、多文件拖放、Mac 截图复制粘贴，以及直接粘贴到题干/配图部分。
- [ ] 一份带文字层 PDF、一份扫描 PDF、跨页题目，检查页码、选区与图片清晰度。
- [ ] 一份包含中文、公式、选项和配图的 DOCX；与 Word 原稿比对，确认复杂对象是否需要改用 PDF。
- [ ] 原稿框选与分区文字/图片混合，变更选项、移动、移除、保存并重新打开草稿。
- [ ] 题干、答案、解析、配图各自顺序正确；预览没有遗漏、重复选项标签或裁掉文字。
- [ ] 不启用云识别，直接手工修改、保存、确认入库、加入题夹和组卷篮。
- [ ] 自行配置 Doc2X 后，确认上传范围、候选校对、采用、保存、确认入库；断网后检查记录保留及续查。
- [ ] 沿用原稿录下一题、复制重组、归档恢复；旧稿、原文件和历史内容仍在。
- [ ] 在 Word/WPS 中打开导出文件，检查文字、公式、配图与答案位置。
- [ ] beta.7 用户可打开“软件更新”，允许测试版后检查 beta.8，下载并安装；更新行为亦由用户验收。

反馈时提供原稿格式、所在页码、操作步骤、实际现象及预期结果；API Key 不需要发给开发者。

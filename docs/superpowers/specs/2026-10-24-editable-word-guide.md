# M18 使用说明与用户验收清单

适用版本：1.1.0-beta.5。功能验收由用户执行；本文件不是开发者已跑过的测试报告。

## 从哪里开始

“题库浏览” → 任意题目的“编辑题目与答案”。也可先选题加入“组卷篮”，再从组卷条目进入编辑。

## 编辑一道题

- 左侧保留原始题图，右侧编辑文字；“题干”和“答案”分别保存各自文档。
- 文字可直接输入或粘贴，支持粗体、斜体、换行和撤销/重做。公式通过公式按钮打开可视输入窗口；已有公式可双击修改。公式源码也可用于输入熟悉的 LaTeX。
- 配图可从本机导入 PNG/JPEG，或从原始题图/答案图拖出矩形框裁取。选中配图可调整宽度、左/中/右对齐和图注。
- 题干、答案分别选择 Word 使用“原图”或“可编辑内容”。只保存编辑稿但继续选原图，导出的仍是原图；这样可以分几次整理一题。
- 点击保存或使用 Mac 的 ⌘S、Windows 的 Ctrl+S。保存后生成新版本；历史版本可预览、恢复。恢复后旧版本仍保留。
- 有未保存修改时离开会提醒。保存出错时请先保留编辑文字，不要直接关闭。

本轮尚未接入 OCR，所以原题中的文字不会自动填入编辑区。扫描题可先手动录入；物理配图不用重画，可从原图裁取。

## 组卷与导出

1. 将需要的题目加入组卷篮，使用上下箭头调整顺序。
2. 可在某题前添加分组标题；“题号（Word / PPT）”留空时按位置自动编号，也可填写自定义题号。
3. 设置试卷标题、副标题、字号、页边距、题后留白、逐题新页和参考答案的位置。
4. 保存排版设置，打开“预览试卷内容”。预览用于核对图文和顺序；实际分页以 Word/WPS 为准。
5. 点击“导出 Word”，选择保存位置。未编辑题目以原图输出；已选择可编辑模式的题目输出文字、原生公式和独立配图。
6. 在 Word/WPS 打开后可继续编辑。复杂公式若转换不受支持，会提示具体题目及公式，不会静默丢失。

“原图 PDF”和“原图 PPT”保留旧输出方式，不采用新编辑内容和 Word 页边距、字号等排版设置。需要编辑后的 PDF 时，可从 Word/WPS 另存。

## 你来验收的项目

建议先用几道副本或练习题验收，再整理大量正式题目。

- [ ] 旧题库仍能打开，原题图、原始答案图及已有题夹仍在。
- [ ] 在题干中修改数字、粗体/斜体、换行，保存后退出编辑再打开，内容一致。
- [ ] 在一句话中插入并修改一个分式、上下标和向量公式，核对公式显示。
- [ ] 从原题框选配图；另导入一张本机图片，调整宽度、对齐与图注，保存重开。
- [ ] 编辑参考答案，确认题干和答案切换不会混淆内容。
- [ ] 保存两次不同内容，在历史中预览第一版再恢复；确认新旧版本均可找到。
- [ ] 只修改编辑稿但保持原图模式，Word 仍输出原图；切换可编辑模式保存后，Word 使用新内容。
- [ ] 将一题原图题和一题编辑题放入同一组卷，调整题序、分组标题、自定义题号，保存重开核对。
- [ ] 分别导出不含答案、题后答案和末尾答案，核对题答顺序及无答案占位。
- [ ] 在你日常使用的 Word/WPS 中打开 DOCX，修改文字、双击公式改变分母或上下标，再保存重开。
- [ ] 单独拖动/缩放 DOCX 配图，确认它没有和题干整页合成一张图片。
- [ ] 检查中文、复杂公式、长题、跨页图片与逐题新页；字体和分页可能因 Office 版本不同而变化。
- [ ] 取消导出对话框；编辑未保存时离开/关闭窗口，确认保留或放弃符合选择。

反馈时请提供操作步骤、期望结果、实际结果；涉及公式时可一并提供公式文本和 Word/WPS 版本。

## 当前边界

没有 OCR 自动识别、Word 导入或表格编辑。配图中的文字和线条仍是图片。复杂 LaTeX 排版与化学命令可能被拒绝，错误会给出可行的修改建议（例如用 `\bar` 代替 `\overline`）。复杂公式及 Word/WPS 兼容性以你的验收结果为准。

已保存编辑内容的题目会禁止旧流程中的重新合并/取消合并，防止该操作丢失编辑稿和历史；需要重新裁切时，请重新导入原 PDF。

原题、编辑文档与版本存储在本机；项目仓库和安装包不包含私人题库。历史配图暂不自动清理，避免恢复旧版本时丢图。“备份数据库”仅保存数据库，完整题库还需要保留存储目录中的 PDF 和图片。

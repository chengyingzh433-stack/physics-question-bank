# Doc2X 单题识别与校对使用说明

适用版本：Mac 1.1.0-beta.6。入口：题库或组卷篮 → 编辑题目 → 页面下方「单题识别与校对」。

本版提供识别接入和校对操作。开发者只做静态审查、类型检查、编译及打包，未调用真实识别服务，未进行功能、界面或 Word/WPS 验收；以下实际使用检查由用户完成。

## 1 费用和工作原理

**Doc2X API 是按解析额度计费的云服务。** 2026-10-25 官方开放平台公开价格为按量 ¥0.02/页起、资源包最低 ¥0.01/页；图片接口每张图片消耗一页解析额度。识别 100 张题干图片是 100 页额度，题干和答案各 100 张则是 200 页。重复发起识别会再次提交，已有本地候选的查看、校对、保存及 Word 导出无需重新识别。实际价格、资源包起购量、有效期和赠送额度以购买时账户页面为准；本程序不代购额度、不自动充值。[开放平台及价格](https://open.noedgeai.com/)、[图片接口计费说明](https://doc2x.noedgeai.com/help/zh-cn/api/doc2x-api-v2-image-interface.html)。

API 额度与 Doc2X 网页版会员互不通用。请在**开放平台**获取 API Key，不要把网页版登录凭据或 ChatGPT 密钥填入本程序。[官方开放平台说明](https://open.noedgeai.com/)。

工作流程：选中的题图副本上传到 Doc2X → 云端进行文字、公式和版面识别 → 返回 Markdown、公式表达和可能附带的图片包 → 本机转成受限可编辑文档 → 用户对照原图校对 → 保存及 Word 组卷。这里接入的是识别服务，未在你的电脑上训练或部署 Doc2X 模型，也不自动求解题目。公式、单位、选项顺序和图表仍需人工核对。[官方图片接口](https://doc2x.noedgeai.com/help/zh-cn/api/doc2x-api-v2-image-interface.html)。

## 2 第一次配置

1. 打开任意已入库题目的编辑页，找到「单题识别与校对」，点击「识别设置」。
2. 点击「打开 Doc2X 控制台」，自行登录并确认账户 API Key 和额度。
3. 回到应用，输入 API Key，开启「启用 Doc2X 云识别」。
4. 默认新密钥只在本次应用启动期间使用。需要记住时勾选系统安全存储；系统不可用时仅允许临时输入，不明文保存。
5. 点击「保存设置」。配置不等于上传，后续每次仍需确认待上传图片。

已有密钥不会回显。更新密钥或改变保存方式时重新输入即可；「清除密钥」会清除本机凭据并停用云识别，保留题目与候选。Mac 包尚未通过 Apple Developer ID 签名及公证，更新后可能需要重新授权系统凭据访问或重新输入密钥。

## 3 识别与校对一题

1. 在编辑页选择「题干」或「答案与解析」。没有答案图时先匹配答案图，或直接手工编写答案。
2. 点击「识别题干原图」或「识别答案原图」，选择整图或框选范围，可缩小副本尺寸。
3. 点击「生成上传预览」。检查实际上传图片的范围、清晰度和体积；超过 7 MiB 时调整选区或缩放。原 PDF 与原图不会改变。
4. 勾选本次上传及使用额度的确认项，点击「确认上传并识别」。只有这份图片副本被发送。
5. 等待时可继续修改当前正文。结果进入候选区，不覆盖现有内容；同一时间只执行一个识别任务。
6. 在候选区对照本次输入图编辑文字、公式及配图。遇到表格、缺图或无法转换的公式，先修正内容，再在对应事项下记录处理方式。必要时使用「原图裁取」补图。
7. 点击「保存候选」。候选有自己的保存按钮；在候选区按 ⌘/Ctrl+S 保存候选，在正文区使用该快捷键保存正式编辑内容。
8. 对照完毕后可勾选已校对并保存候选。未处理事项会阻止采用，服务返回结果本身不代表内容正确。
9. 点击采用入口，选择替换或追加到当前部分。另一部分及原有 Word 导出模式保持不变；采用前自动保存整题恢复草稿。
10. 检查右侧编辑稿，按需把「Word 导出使用」改成「可编辑内容」，点击顶部「保存」。之后在组卷篮沿用已有 Word 导出流程。

「已加入编辑稿」表示尚未保存；「已保存到题库」才表示当前编辑稿已成为正式版本。正文或候选继续修改时会回到待复核，可再次人工确认。追加后的整段内容需要重新核对。

## 4 恢复和异常处理

- **误替换、误追加：** 打开「恢复草稿」，选择采用前快照，查看题干和答案后恢复。恢复只进入编辑态，核对后再保存；恢复动作也会先保留现有完整草稿。
- **正式历史：** 原有「历史版本」继续可用；恢复正式历史会产生新正式版本。未保存当前稿在恢复前另存为恢复草稿。
- **识别期间修改了正文：** 采用时会要求确认，仍会先保留当前完整草稿。其他窗口已更新正式版本时，先保留草稿并加载最新版本，再决定如何采用。
- **原图改变：** 采用旧候选需要对照旧输入图和最新原图，重新确认。原图不可读时保留候选并停止采用，请先修复原图或答案绑定。
- **取消或关闭：** 「停止本地等待」不保证取消远端处理或退费；重开不会自动重新上传。已有任务号可「继续查询原任务」。
- **提交状态不明：** 无任务号时不能确定是否已经计费。先查看开放平台记录，再决定是否重新准备并确认上传；应用不会自动重投。
- **结果过期：** 已保存候选及配图继续保留在本机。远端结果已不可用且本机没有候选时，需要自行决定是否重新识别。
- **候选丢弃：** 软丢弃不删除正式内容及其来源历史，工作区提供恢复候选入口。
- **资料目录迁移：** 正在识别或保存图片时暂停迁移；停止等待并结束当前保存后再操作。

## 5 已知边界

- 首版只识别现有题干或答案图片，不包含整卷批量识别、自动切题、自动作答、Word 导入或可编辑表格。
- 不保证每张题图都返回完整配图或精确坐标；缺图、复杂表格用原图裁取补全。不支持的公式保留原文和处理提示。
- 原始识别 Markdown 保存在本地候选中；超过单题本机处理上限的异常响应会明确拒绝，任务记录与原图保留。
- 候选、恢复草稿及正式版本分开保存；为防止误删，候选软丢弃不会自动回收其图片，长期使用可能增加磁盘占用。
- 持久化任务默认暂停后续等待，重新打开应用时需手动继续查询。保存在系统安全存储中的 Key 不属于试卷数据，迁移到另一台电脑后需重新配置。
- 本次安装包为 Apple Silicon Mac（M 系列，macOS 13 或更新）；没有 Intel Mac 或新版 Windows 安装包。代码继续使用平台路径和 ⌘/Ctrl 快捷键，Windows 功能未验收。

## 6 由用户执行的自测清单

可选约 12 道实际题目，包含清晰印刷题、扫描题、公式密集题、图表混排题及答案，记录错字、公式结构、漏图和校对耗时。

- [ ] 未启用识别时，手工编辑、保存、历史版本和 Word 导出仍可用。
- [ ] 设置可启用、停用、更新、清除；临时 Key 重启后需重填。
- [ ] 题干与答案目标准确；整图、选区和缩放预览与实际意图一致。
- [ ] 识别返回后可对照原图校正文字、公式、选项和配图。
- [ ] 表格、缺图或不支持公式有提示，处理决定及原始 Markdown 重开后仍在。
- [ ] 等待期间继续编辑，候选返回不会覆盖新内容。
- [ ] 候选独立保存；替换或追加只改变所选部分；草稿可以恢复。
- [ ] 旧候选、正式版本和校对状态关联正确，恢复历史不会冒用新状态。
- [ ] 断网、暂停、重启、额度不足等情形下原件不受损；不会未经确认重新提交。
- [ ] Word 导出模式、题序、答案位置、文字、公式及配图符合预期。

以上项目未由开发者代为执行。反馈时提供操作步骤、应用提示及问题类型即可；请勿把 API Key 附在截图或问题描述中。

# 题库分类、检索与选题：设计和 Doc2X 模块对照

日期：2026-10-22。用户已选定此项优先，并要求其他两项按顺序进入执行目录。

## 对照依据与取舍

依据 Doc2X 的[教师题库公开教程](https://doc2x.noedgeai.com/help/en/tutorials/teacher-question-bank.html)以及本项目源码，未登录其私有工作台或测试其识别准确率。借鉴其按个人目录整理、组合查找、选择后组卷的工作方式；用本项目的 React/Mantine/SQLite 实现。

| 模块 | 本项目已有 | Doc2X 文档展示的能力 | 本轮取舍 |
|---|---|---|---|
| 资料录入 | PDF、人工裁切、编号、入库题图、答案匹配 | 导入和审校后存入题库 | 保留已测通的链路 |
| 分类组织 | 章节、知识点等学科标签 | 题库及目录组织 | 新增个人题夹，与章节并存 |
| 查找 | 固定条件组合筛选 | 搜索配合筛选 | 增加现有资料/标签文本检索、答案状态、未归类筛选 |
| 选题 | 勾选立即入篮，无法在卡片取消；无批量整理 | 选择题目后进入组卷流程 | 分离勾选和入篮，支持批量归类、去重入篮、取消入篮 |
| 内容编辑 | 完整题图，不含可编辑正文 | 编辑题目内容 | 第二阶段做，当前不声称正文可搜可改 |
| 输出工作区 | 组卷篮、PDF/PPT 导出 | 材料编辑与多种输出 | 第二阶段补编辑和 Word，第三阶段统一导航 |

三种可行范围：仅补搜索最省工作但无法体现个人积累；全面重做题库/团队/材料平台跨度过大；本轮选择独立个人题夹加检索选题闭环，直接服务老师整理好题的需求。

## 行为设计

1. **题夹：** 全部题目、未归类、自定义题夹；支持新建、重命名、删除。题夹名去首尾空格、1–60 字、不得同名。同题可属于多个题夹。移出或删除题夹只删关联，不删原题、答案和组卷条目。
2. **检索：** 输入词匹配试卷名称、有效出处、题型、章节、知识点；按字面包含匹配，`%`、`_` 不当通配符。可与现有条件、题夹、答案状态 AND 组合；多知识点命中任一。页面说明搜索范围，不提供伪正文搜索。
3. **选题：** 卡片复选框仅代表本次选中；全选仅作用于本页。分页保留已选，切换筛选时清空并有固定提示。批量加入题夹/组卷篮；当前题夹允许批量移出。入篮自动去重；成功后清空本次已选，失败保留便于重试。
4. **预览：** 缩略图定高便于浏览，点开显示完整题图、来源、标签和答案图；支持上一题/下一题、加入或移出组卷篮。缺答案明确显示“未匹配答案”。
5. **列表：** 每页 24 题，显示结果数、已选数和篮内数；切换条件回第一页；无结果与加载失败区别显示。旧请求不得覆盖新筛选结果。

## 数据与接口

- 新增 `question_folders` 和 `question_folder_items`，复合主键防重复、外键级联清关联。启动时 `CREATE TABLE IF NOT EXISTS` 幂等建表，旧题默认未归类。
- 现有 `QuestionFilterCriteria` 扩展 `search`、`folder_id`、`unfiled`、`answer_status`；主进程统一构造参数化 SQL，现有列表接口保持兼容。
- 新增题夹 CRUD 和批量关联 IPC、批量入篮和按题 ID 出篮；批量写入使用事务，校验题目确实已入库且属于题目卷，失败整批回滚。
- 本轮仍沿用返回匹配结果的列表 API，分页限制屏幕图片数量，不声称已实现数据库分页。后续大题库可独立改为查询分页。
- 组卷变化发出渲染进程事件刷新导航数量，数据库仍是唯一持久状态。

## 验收边界

使用内存 SQLite 验证同题多题夹、重复归类、删除安全、组合检索、字面特殊字符、答案卷隔离、批量事务、篮去重。运行 typecheck、Vitest 和 build。用隔离测试数据检查默认窗口的布局、批量操作、搜索、预览及分页；真实老师资料验收单独记录。原始数据不用于自动化写入测试。

# M22 单题录入与题卡使用说明

适用版本：Mac 1.1.0-beta.9。功能与实际使用验收由用户完成，开发者未运行功能测试。

## 1 方便地录入一道题

从左侧“录题工作台”开始：

- **一张图片：** 点“选择图片 / PDF / Word”，选择 PNG/JPEG，直接进入校对页。原文件和录入快照都会保留。
- **复制的截图：** 复制后点“粘贴截图或文字录题”，直接进入校对页；剪贴板中的纯文字也可这样录入。
- **PDF / Word：** 选择 PDF 或 DOCX 后，选页、框选当前题目，再点“继续校对与选标签”。如果还没有加入组成部分，会直接把当前选区（未框选时为整页）作为题干。
- **复杂题目：** 点“分区组题 / 手工输入”，分别加入题干、选项、答案、解析和配图；可以跨页、混合多个原稿、调整顺序。文件拖放和工作台内 ⌘V / Ctrl+V 粘贴保留。
- **输入了文字：** “暂存”或“继续校对与选标签”会自动把输入框中的文字加入当前部分，不必先点“加入组题”。需要分段添加时仍可使用该按钮。

“预览组合”现在是可选操作。普通题不必先打开预览弹窗并勾选确认。

## 2 校对时直接选标签

校对页的“标签与来源”支持题型、章节、难度、多个知识点、年份和出处，均可留空。章节支持已有模板和自定义；知识点可以输入名字后点“新建并选中”。这里新增的分类项可被其他题目继续使用。

标签和题目内容一起保存。尚未完成时点“暂存草稿”或 ⌘S / Ctrl+S；完成后在页底勾选已核对题干、选项、答案、配图和标签，再点 **“保存并入库”**。一次保存同时提交正文、标签和入库状态，无须先单独保存正文再入库。失败会保留当前输入；其他窗口修改过内容或标签时会提示冲突，不覆盖新版本。

已入库的题目在“题库浏览”点 **“编辑题目 / 标签”**，修改后点“保存题目和标签”。标签侧栏用于筛选；真正给题目选标签是在编辑页。

## 3 编辑与 Doc2X

纯文字可以直接修改，公式可用公式按钮插入，配图可独立调整大小、对齐和图注。校对编辑区也支持直接粘贴一张 PNG/JPEG 图片，不再要求先存成文件。

截图或扫描件进入校对时仍是图像。需要可编辑文字时，在下方 Doc2X 区域选择题干或答案、预览上传副本并确认，识别后处理提示、保存候选并采用。仅录入、继续校对或保存入库不会调用云服务。API Key 及云端额度规则沿用 [Doc2X 说明](2026-10-25-doc2x-ocr-guide.md)。

尚未保存的识别候选须先保存或处理；整题入库前仍需你核对。新录题最终只需一次整题确认，涵盖题干和答案；旧题的识别校对状态与历史版本保留。系统不自动生成物理解答，也不自动选知识点。

## 4 题卡同步最新内容

确认入库或保存已有题目后，返回“题库浏览”：

- 卡片和放大预览优先显示最新保存的文字、公式和独立配图；没有编辑内容的部分仍显示原图。
- 卡片显示题型以及章节、难度、知识点摘要；点击放大可查看完整标签。
- 已保存的文字答案也算“有答案”，与答案筛选口径一致。
- 放大预览可切换“最新保存的题卡”与“对照原图”。原图维持录入时的内容，供校对追溯。
- 小卡片只展示题目上部，长题请点击放大。读取失败明确提示，可重试；不会用旧图冒充最新编辑稿。

题卡显示与导出选择分开：Word 仍按编辑页“Word 导出使用”选择原图或可编辑内容；PDF/PPT 仍采用原图。本阶段没有增加编辑稿重新合成 PNG 的导出按钮。内容历史恢复不会回滚标签。

## 5 范围与格式

只完善单题录入，没有批量自动分题。PNG/JPEG、PDF、DOCX 的格式与容量限制沿用 [M21 格式说明](2026-10-25-multi-source-intake-guide.md#5-格式与容量边界)。旧 DOC 请转 DOCX 或 PDF；复杂 Word 排版、旧公式和特殊图片可能仍需先转 PDF。

本轮提供 Apple Silicon Mac DMG，保留 Windows 快捷键、路径与文件选择兼容，但未制作或验收 Windows 新包。原始资料和识别记录不随软件更新删除。

## 6 用户自测清单

以下待你实际执行，不表示功能已经验收通过：

- [ ] 选择一张图片、粘贴截图、粘贴文字，检查能否直接进入校对，并保留原件。
- [ ] 各取一份 PDF 和 DOCX，选择页码并框选单题，直接继续校对；检查复杂 Word 内容是否完整。
- [ ] 分别加入文字、选项与配图，输入未点“加入组题”的文字后直接继续，检查内容不遗漏、不重复。
- [ ] 在校对页选择题型、章节、难度和多个知识点；新建一个知识点，填写年份与出处，一次保存入库后重开核对。
- [ ] 编辑已有题目的文字、公式、图片和标签，保存后返回题库，检查卡片、放大预览、标签筛选同步；“对照原图”仍是原始内容。
- [ ] 给没有答案图的题添加文字答案，检查卡片“有答案”及答案筛选；清除时按页面提示选择合适的 Word 导出模式。
- [ ] 在题干和答案编辑区直接粘贴图片，检查插入位置、缩放、保存与重开。
- [ ] 自行使用 Doc2X，核对候选保存、采用、整题确认与入库；密钥不要提供给开发者。
- [ ] 暂存后退出重开，或取消文件选择、遇到错误后继续草稿；原资料和编辑历史仍在。
- [ ] 检查软件更新中的 beta.9 下载与安装，以及 Word 实际导出效果；这两项亦由你验收。

# 测试版问题 2：章节模板与知识点搜索选择

用户要求：章节可套用预设，也可自定义，后续可扩展其他学科模板；首个模板明确选择人教版（2019）。知识点保留自定义，改用输入几个字即可匹配并选择的下拉菜单。

## 实现

- 默认提供高中物理人教版（2019）六册目录：必修三册、选择性必修三册，共 27 章、125 节，连同册节点共 158 项。菜单按模板和册分组，显示完整路径并支持关键词查找。
- 后期处理、复查和题库筛选共用章节选择组件；“章节模板 / 自定义”入口可重复套用预设，或在指定上级章节下创建个人章节。
- 模板注册表独立保存在 `src/shared/chapterTemplates.ts`，每个模板包含学科、版本和稳定节点标识。后续增加其他学科只需追加模板数据，选择与安装流程可复用。
- 章节表增加父节点及模板标识。升级只增加列和预设，不重新编号旧章节；重复套用不产生重复目录，不覆盖已有题目归类。
- 题库选择册或章时包含下级章节的题目；搜索支持完整章节路径。
- 知识点改为搜索多选，最多展示 8 个匹配候选，前缀匹配优先；已选项显示为可移除标签，输入新名称时可点击输入框右侧“新建并选中”。同名创建自动复用，不重复添加。

- [选择性必修第一册](https://www.renjiaoshe.com/jiaocai/2061.html)、[选择性必修第二册](https://www.renjiaoshe.com/jiaocai/2062.html)、[选择性必修第三册](https://www.renjiaoshe.com/jiaocai/2063.html)

模板随软件本地提供，使用时无需连接网站。当前内置一个版本；其他学科和版本可后续补充，不在本轮自动生成未经核对的目录。

## 本轮发现并修复的问题

- 后期处理批量知识点接口原先查询不存在的 `created_at/updated_at`，且返回对象数组，与 `Map<number, number[]>` 契约不符。改为直接读取题目—知识点关系中的数字 ID，恢复重开回显。
- 知识点创建按钮原先可能被下拉层遮挡，且输入失焦会清空搜索词。现置于输入框右侧，鼠标按下时保留输入焦点。
- 修正渲染进程 `env.d.ts` 的共享类型导入路径，让 API 调用获得实际类型检查。

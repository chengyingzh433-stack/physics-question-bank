# M19 Doc2X 单题识别与校对交付记录

日期：2026-10-25。版本：1.1.0-beta.6。用户已批准按方案实现 Doc2X 路线，并授权制作 Mac DMG 上传 GitHub。功能验收由用户执行。

## 实现范围

- 编辑页新增「单题识别与校对」：独立题干/答案目标、整图或选区、缩小副本、明确预览和本次云上传确认。
- Doc2X API Key 默认仅本次启动使用，可选操作系统加密存储；可停用、更新和清除，普通设置表不含明文密钥。
- 单并发异步提交与查询，提交成功记录远端 UID；暂停、重开、超时或未知提交状态不自动重传。查询仅使用原任务号。
- unified/remark 解析 Markdown、数学表达；沿用已有 Word 公式转换能力。有效配图保存为本题资源；HTML 不执行、任意外链不下载、ZIP 解包限制路径与体积。
- 识别结果成为独立候选，保留原始 Markdown、问题事项和处理决定；候选可以编辑、保存、软丢弃及恢复。转换失败时仍保存有界原文供人工整理。
- 替换/追加只影响目标部分，先持久化完整未保存恢复草稿；检查正式版本、草稿和原图变化，原图变化确认绑定最新指纹。历史正式版本恢复也先保护当前草稿。
- 采用仅返回编辑稿，正式保存才形成版本；来源与人工校对状态随版本保留。编辑后降级待复核，追加或采用旧原图结果也需复核。
- Mac/Windows 共享平台路径和 ⌘/Ctrl 快捷键；资料迁移与异步识别/图片保存互斥。旧合并/取消合并不能静默删除含识别记录的题目。

原 PDF、原题图和原答案图未被识别流程覆盖。未安装 MinerU 或其他本地模型；未接入整卷批量 OCR、自动答题、Word 导入或可编辑表格。

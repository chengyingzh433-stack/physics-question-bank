# M21 多来源录题交付记录

日期：2026-10-25。版本：1.1.0-beta.8。基线：beta.7 的应用内更新版本。用户确认同时实现原稿框选和文字、图片分区输入。

## 实现范围

- 录题工作台、草稿列表、原稿多选/拖放、剪贴板截图和文字、PNG/JPEG、PDF、DOCX 本机预览。
- 题干、选项、答案、解析、题干配图、答案配图六种角色；原稿框选与直接文字/图片输入混合组题、排序、移除、保存、复制与归档恢复。
- 本机生成题干/答案快照，自动建立初始可编辑稿，沿用 Doc2X 单图候选校对、采用、版本保存及 Word 导出。
- 待校对稿独立保存，用户确认后才进题库、题夹和组卷篮；原稿、旧快照和识别历史保持独立。
- DOCX 复用 docx-preview，页面副本复用 html-to-image；附组件和传递依赖许可。预览前限制 ZIP 解压和图片尺寸、移除外部资源关系与嵌入活动内容；界面将 Word 放在不运行脚本的隔离页面中，不自动上传文档。

范围与操作见 [实施方案](../plans/2026-10-25-multi-source-intake-plan.md)、[使用说明与用户自测清单](2026-10-25-multi-source-intake-guide.md)。

## 边界与下一步

支持 DOCX；旧 DOC、宏及加密 Word 先转换。Word 复杂版式、旧公式、外链资源和特殊图片可能与原文档不同，提示改用 PDF。每次用户组合一道题，没有整卷自动分题和批量云识别；Doc2X 不替代物理内容正确性的人工判断。输入框文字需先“加入组题”才成为可保存的组合。

本阶段不自动删除来源和移除的图片资源；完整备份仍须包含数据库和整个项目资料目录，不能只备份 app.db。Windows 保留路径与快捷键兼容，但未制作或验收新的 Windows 安装包；Mac 包仍无 Developer ID 签名与公证。

下一步先根据用户真实材料反馈修正录入问题，再考虑录入队列/批量分题、结构化选项、统一导出与完整资料备份，不在本阶段自动启动这些开发。

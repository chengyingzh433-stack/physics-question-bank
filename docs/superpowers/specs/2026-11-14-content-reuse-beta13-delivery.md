# beta.13 第一阶段：正文搜索与一致导出

日期：2026-11-14。功能实现完成，待用户功能验收。

对应 [第一阶段改进计划](../plans/2026-11-14-product-improvement-roadmap.md)。本版包含 beta.12 的整道题直接录入入口。

## 本版入口与操作

1. 进入“我的题库”，在原搜索框输入已保存题干或答案中的词。结果显示“题干”“答案”或“资料 / 标签”及匹配片段。编辑、保存、恢复历史后会更新搜索文字。
2. 纯原图没有文字的题，仍按已有名称和标签搜索；识别候选和未保存文字不作为正式正文搜索。软件不会为搜索自动上传题图。
3. 旧编辑记录启动时在本机补建搜索文字；需要重建时，在“分类 / 筛选”底部点击“重建本机搜索文字”。跳过无法读取的记录会提示数量，原件不改动。
4. 进入“组卷篮”，在“内容来源（三种格式通用）”选择“最新保存内容”“原始题图与答案图”或“沿用每题原有导出偏好”。新设置默认最新内容；已有旧设置保留为沿用偏好并显示蓝色说明，需要时手动切换。
5. 题干、答案分别处理：最新内容使用已保存编辑稿；从未编辑的部分使用原图。清空答案并保存后表示暂无答案，切换旧偏好不会改变这个事实；主动选择原图仍可查看原始答案。
6. 点击“预览试卷内容”检查当前选择；设置标题、题号、分组和答案位置，然后导出 Word、PDF 或 PPT。导出会重新读取已保存内容并固定题序、内容版本及图片字节，后续编辑不会混入正在生成的文件。

## 导出边界

- Word 继续输出可编辑文字与 Office 原生公式。图片中的文字不会自动变成文字；既有复杂公式转换限制仍保留，不能转换时给出明确错误。
- PDF/PPT 使用所选内容重新排版后输出图片。内容可以对应最新编辑稿，但导出后的正文不能逐字编辑；这不等同于原生文字 PDF 或可编辑 PPT 文字框。
- PDF 为 A4，PPT 为宽屏；字号、边距、题后留白影响排版。PPT 每题另起页，长题续页；PDF 可连续排题或逐题新页。三种格式内容来源一致，换行与分页不保证相同。
- 编辑文字按行分页，公式及较小配图尽量保持完整；长题图按设定宽度连续分段，不强制压缩到单页。图片内没有可用于断行判断的文字结构，分页边界可能经过图中文字或示意图，需用户核对。
- 过宽公式、超出单页的不可拆分文字/公式块、过长页眉、缺失或损坏资源会提示调整，不自动换成旧题图。无法导出的题可修正，或从组卷篮明确移除后再导出，不会被静默跳过。
- 本机渲染使用应用自带中文和公式字体，不访问外部识别或渲染服务。单次图片快照/输出图片分别限制 384 MB，最多 500 页；单次页面加载、排版或绘制超过 60 秒会停止并提示重试。
- 仅搜索已有文字及 LaTeX 字面内容，不做公式等价、语义或图片文字搜索。历史旧版本中已丢失的“清空答案”意图不能凭空推断；本版重新清空并保存后独立记录该状态。

## 数据与兼容

- 原 PDF、原题图、答案图及历史内容均保留。搜索表为本机派生资料，正文保存和索引更新在同一数据库事务中；删除题目级联清理索引。
- 新增 editedParts 保存“曾明确编辑”的状态，与旧导出偏好分离；历史恢复使用该历史的完整内容，不混入后来的编辑状态。
- 不建议用旧版本编辑本版的新数据，旧版本不认识新的清空状态。旧应用副本用于必要时恢复，回退资料应使用升级前完整备份。
- 当前交付目标为 Apple Silicon Mac。保持跨平台路径及字体定位；本轮未做 Windows 或 Intel Mac 运行验收。

## 用户自测清单

- 输入“加速度传感器”或自己保存过的题干词，核对题干命中；输入答案词，核对答案命中。
- 修改一个独有词后保存，核对新词命中、旧词不再作为当前正文命中；恢复历史后再核对。
- 将题目加入组卷篮，选择最新内容，分别导出三种格式，核对数字、公式、配图、题号及答案位置；主动选择原图再对照。
- 清空答案并保存；再切换本题旧导出偏好，确认最新题卡仍为空，原图模式仍能看到旧答案。
- 纯手工题、只有原图的题、无答案题、跨页长题或长题图各核对一次。
- 原图/编辑稿混合题，分别核对题干与答案；原有 Word 偏好是否清楚展示。
- 缺图或公式不支持时，错误明确且没有生成悄悄漏内容的文件；取消保存对话框不改动已有文件。

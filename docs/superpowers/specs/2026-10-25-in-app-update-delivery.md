# M20 应用内更新交付记录

日期：2026-10-25。版本：1.1.0-beta.7。用户明确授权仓库公开、代码上传、DMG 发布及本机安装。

## 功能范围

- 公开 GitHub Releases 更新源，不要求用户配置 GitHub 令牌。
- 应用设置及顶部“软件更新”入口，启动检查开关、测试版开关、版本说明、下载进度、取消和安装。
- 主进程控制下载地址、版本及处理器匹配；文件大小与 SHA-256 校验成功后才允许安装。
- Mac 应用替换保留旧程序，取消退出取消本次更新，失败尝试恢复；不更改题库、图片、PDF 和密钥文件。
- Windows 有相应 EXE 时交给安装程序；本轮只交付 Apple Silicon Mac 包。
- 新增发布校验文件生成命令，后续版本保持同一命名及发布约定。

说明与用户自测清单见 [使用说明](2026-10-25-in-app-update-guide.md)，实施范围见 [方案](../plans/2026-10-25-in-app-update-plan.md)。Doc2X API Key 申请、配置及费用亦写入使用说明。

- 更新缓存不等于题库备份，旧应用备份不等于数据库回滚。

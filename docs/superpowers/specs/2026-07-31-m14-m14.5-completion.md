## 3. WorkflowLayout 双流程隔离（附带修复）

### 问题
人测发现：答案卷裁切时点顶栏"后期处理"/"原卷复查"会跳到题目卷，流程混乱。

### 根因
`WorkflowLayout.tsx` 只有一套步骤（裁切→后期→复查→答案），答案卷和题目卷都用它，所以 navPaperId 统一解析为父卷 id → 点步骤栏的任何按钮都跳题目卷流程。

### 修复
`WorkflowLayout.tsx` 重写为两套独立步骤：

| 场景 | 步骤栏 | 链接目标 |
|---|---|---|
| 题目卷 | 裁切 → 后期处理 → 原卷复查 → 答案匹配 | 全用题目卷 id（sky 主色） |
| 答案卷 | 裁切答案 → 整理答案 → 答案匹配 | 裁切/整理用答案卷 id，匹配用父卷 id（violet 主色） |

根据 `paper.kind` 动态切换步骤集，答案卷顶栏显示"答案卷"标记。

### 验证
答案卷流程里点"整理答案"不会跳题目卷，题目卷流程里点"原卷复查"不会跳答案卷。

## 4. 人测发现的小问题

### 问题 1：撤销上一刀"没用"
**根因**：撤销是按当前可见页（`activePage`）作用域的，不是全局时间线。在第 2 页画刀后滚回第 1 页点撤销 → 对第 1 页撤销 → 无刀可撤 → 无反应。
**解决**：告知用户滚到有刀的页再撤销，或直接点线删除（裁切工具模式下点线可删）。
**决策**：设计限制，不改（改成全局栈会打破页隔离，且 created_seq 是按页分配的）。

### 问题 2：连续点击"确认绑定"会否重复入库？
**答案**：不会。UI 层 `busy=true` 禁用按钮；文件层固定文件名 `a_{qid}.png` 后写覆盖前写；DB 层 UPDATE 不会产生重复行。

### 问题 3：绑定后查看答案
**现状**：M14 只做了"绑定"（写 `answer_image_path`），还没做"查看"入口（题库 Modal / 复查页折叠区）。
**决策**：留 M15 全链路走查时一并验证，或作独立 UX 需求。

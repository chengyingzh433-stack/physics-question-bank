# M23 单题录入流程修复交付记录

日期：2026-10-25；版本：1.1.0-beta.10；基于 beta.9。

## 实际发现与修复

本次用户明确要求开发者打开软件进行真实操作，随后要求给出并执行修复方案。使用自建题目，未改动原有空草稿。

- beta.9：首页只呈现 PDF 裁切入口；上传图片后首屏说明与标签挤占正文；切换“答案与解析”触发空文档 `content.some` 异常；重试后未提交文字及标签丢失。
- beta.10：统一空文档格式，预览与内容判断兼容空答案；编辑器 `setEditable` 不再触发正文更新。正文输入后自动使用可编辑内容，清空时可回到原图模式。
- 正文和标签修改保存本机恢复副本，重进提示恢复；正式版本/标签变化时恢复前确认。存储失败提示及时暂存。已保存数据库、原稿及资源保持独立。
- 软件打开即进入统一录题页，提供图片/PDF/DOCX、粘贴、拖放及直接文字输入。主导航收敛为录题、我的题库、组卷篮；整卷裁切和模板位于更多工具。
- 校对首屏展示原稿和正文，标签位于正文之后，可直接跳转；图片转文字在侧栏按需打开，导出与原稿组题说明折叠。最终按钮直接保存入库，完成页提供下一题和题库入口。

方案见 [实施方案](../plans/2026-10-25-intake-flow-repair-plan.md)，操作与验收见 [使用说明](2026-10-25-intake-flow-repair-guide.md)。

## 已知边界

本机恢复副本依赖应用本机存储空间，写入失败时应使用暂存；不能替代备份，也不保存识别候选的未提交修改。跨设备迁移正式题库不包含此恢复副本。默认不自动上传原稿。旧 DOC 需转换；不增加批量录题、AI 解题或 PNG 合成导出。PDF/PPT 仍使用原图。Mac 包未做 Developer ID 签名与公证。

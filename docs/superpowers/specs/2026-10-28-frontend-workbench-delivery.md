# beta.11 前端工作台：操作与交付记录

## 本次变化

- 统一录题、题库、组卷的导航、配色、间距和控件层级；收窄主导航，让内容成为工作区主体。
- 首页三个入口：选择文件、粘贴截图或文字、直接输入。未完成草稿继续保留。
- PDF / DOCX 默认框选整题，直接进入校对；跨页拼接及分别录入题干、选项、答案、配图放在“分区组题”里。
- 原稿在面板内滚动，底部“继续校对”常驻；新选区未加入已有组成部分时会明确提示，避免悄悄遗漏。
- 校对页右侧直接选择标签；原图对照按需展开，图片大小与图注选项折叠，正文优先。
- 题库改为宽题卡，题夹和组合筛选通过“分类 / 筛选”打开，保留全部条件与多选操作。
- 组卷中分组题号、高级排版折叠；区分“图文编辑稿”“图片编辑稿”“原图题干”，避免将图片误认为可编辑文字。

## 推荐操作

1. 左侧“录入题目” → “选择文件”，打开 PDF、DOCX 或图片；也可在首页粘贴截图/文字。
2. PDF 在原稿中拖动框住一道完整题。需要多个区域时打开“分区组题”，每个选区明确加入对应部分；直接文字也能在分区工具中录入。
3. 点底部“继续校对”。修改正文，切换“答案与解析”，在右侧选题型、章节、难度、知识点、年份与出处。
4. 需要图片转文字时主动打开识别功能；其余操作在本机完成。核对后“保存并入库”。
5. 在题库查看最新题卡，加入组卷篮；设置试卷标题和答案位置，预览后导出 Word，或导出原图 PDF / PPT。

## 用户自测清单

- 首页文件、粘贴、直接输入三种入口是否符合使用习惯。
- 框选整题 → 直接校对；分区工具内图文交替、选项、答案和跨页配图。
- 标签与正文一起保存，题卡同步；退出未保存状态时提醒与恢复是否符合预期。
- 筛选抽屉、题夹、多选入篮；组卷题序、题号、答案位置及导出。
- Word / WPS 中真实排版、公式与配图是否满足需求；复杂 DOCX 仍需特别核对。
- 暗色主题、较窄窗口、长题干和较多标签的可用性。

## 已知边界

图片不会自动变成文字；需要手工输入或主动使用 Doc2X。PDF“读取本页文字”读取的是整页文字层，不是框内精准识别。扫描 PDF 仍需保留题图或识别。DOCX 预览可能与原 Word 分页不同，旧 DOC 需另存 DOCX/PDF。Mac 当前提供 Apple Silicon 版，尚无 Developer ID 签名与公证，未构建 Intel Mac 或新版 Windows 安装包。

下一阶段建议为[同一份原稿连续录题](../plans/2026-10-28-continuous-single-question-plan.md)：保存后回到相同页和位置、可选沿用标签，保持逐题确认，不做批量录题。

# 物理教师题库管理系统需求蓝图

日期：2026-07-06

## 1. 我想做什么

我想做一个面向物理教师的 Windows 题库管理系统。

这个系统主要帮助教师处理手上已有的 PDF 试卷，把整张试卷拆成一道一道可以单独管理的题目。处理完成后，这些题目可以进入题库，以后可以浏览、筛选、勾选、重新组卷，并导出成新的 PDF 试卷。

我希望它首先解决教师日常整理试卷和复用试题的问题，而不是一开始就追求全自动识别。

## 2. 使用者是谁

主要使用者是中学物理教师。

这些教师手里通常有很多 PDF 试卷，例如月考试卷、期中试卷、期末试卷、模拟卷、专题卷、复习卷等。

教师希望把这些旧试卷变成可复用的题库资源，而不是每次出题时都重新翻 PDF、截图、复制、排版。

## 3. 要解决的问题

教师手上的 PDF 试卷通常只能整份查看，不方便单独抽取某一道题。

物理题经常包含公式、图片、电路图、实验图、受力分析图等内容，如果完全依赖自动识别，可能会出现边界识别错误、公式识别错误、图片丢失、题目跨页处理不好等问题。

所以这个系统需要提供一个人工可控的拆题流程，让教师可以直观看到试卷内容，并自己决定在哪里裁切、哪些内容删除、哪些片段合并成一道题。

拆好的题目还需要能被整理、打标签、搜索和重新组卷。

## 4. PDF 试卷导入

教师可以把一份 PDF 试卷导入系统。

导入时，教师可以给这份试卷设置名称，例如“高一物理期中测试卷”“2024 年九年级物理模拟卷”等。

导入后，这份试卷会作为一个独立的试卷项目保存。以后教师再次打开它时，可以继续查看和编辑之前的处理结果。

## 5. PDF 裁切工作区

导入 PDF 后，教师进入裁切工作区。

裁切工作区需要能清楚地显示 PDF 页面。教师可以适应宽度查看，也可以放大、缩小和滚动页面。

教师进入裁切模式后，可以通过点击页面上的某个横向位置，在那里切一刀。

点击前，页面上应该显示一条横向示意线，让教师知道这一刀会切在哪里。

点击后，这条裁切线会固定显示出来。教师可以继续往下点击，把整张试卷切成一段一段的内容。

裁切线需要支持撤销或删除，避免点错以后无法修改。

这个阶段不要求教师马上判断每一段是不是完整题目，只需要先把试卷按横向位置切成多个片段。

## 6. 后期处理工作区

裁切完成后，教师进入后期处理工作区。

这里会按原试卷顺序显示刚才切出来的所有片段。

教师可以删除不需要的片段，例如页眉、页脚、试卷标题、考试说明、空白区域等。

教师也可以多选几个片段，然后把它们合并成一道题。

这个功能主要用来处理跨页题。有些题目前半部分在上一页末尾，后半部分在下一页开头。教师可以把这几个片段选中，再合并成一道完整题目。

如果合并错了，教师应该可以取消合并或重新处理。

经过这一轮清理后，系统中应该只剩下真正需要进入题库的一道道题目。

## 7. 题型模板

很多试卷的题型顺序是固定的，例如前面是单选题，中间是多选题，后面是填空题、实验题、计算题。

系统需要支持题型模板。

教师可以创建一个模板，说明第几题到第几题属于什么题型。

例如：

- 第 1-8 题：单选题
- 第 9-12 题：多选题
- 第 13-16 题：填空题
- 第 17-20 题：实验题
- 第 21-24 题：计算题

处理完一套试卷后，教师可以套用模板。系统会按照题目顺序自动给题目标注题型。

教师也可以手动修改某一道题的题型。

## 8. 题目入库

试卷处理完成后，每一道题都可以进入题库。

题目进入题库后，至少应该能看到：

- 题目内容
- 题型
- 来源试卷
- 在原试卷中的顺序
- 是否由多个片段合并而成

题目需要保留原试卷中的视觉效果。物理题里的公式、图像、表格和实验图不能因为入库而丢失。

同一道题既可以在原试卷中查看，也可以在题库工作区中查看。

## 9. 原试卷浏览

教师可以打开某一套已经处理过的试卷。

打开后，系统应该按原试卷顺序显示这套试卷中的所有题目。

这个视角主要用于复查、补充标签、修正题型、查看来源和继续编辑。

教师应该能从这里看出一套试卷被拆成了哪些题，每道题目前是什么状态。

## 10. 题目编辑与标签

题目入库后，教师可以进入编辑模式，为题目补充更多信息。

需要支持的标签包括：

- 章节
- 知识点
- 难度

章节、知识点、难度标签可以提前创建，也可以在编辑题目时临时创建。

一道题可以有多个知识点标签。

难度可以按教师自己的习惯设置，例如“简单”“中等”“较难”“压轴”等。

教师后续应该可以修改这些标签。

## 11. 题库浏览与筛选

系统需要有一个题库工作区，用来集中浏览所有已经入库的题目。

教师可以按不同条件筛选题目，例如：

- 题型
- 来源试卷
- 章节
- 知识点
- 难度

题目列表中，每道题都应该能看到它的题目内容和来源信息。

例如，教师在浏览单选题时，可以看到每道题来自哪一套试卷。

筛选条件应该可以组合使用。比如教师可以筛选“单选题 + 力学 + 中等难度”。

## 12. 选题与组卷

教师可以在题库中勾选题目。

勾选后的题目可以加入一个临时的组卷区域。

在组卷区域里，教师可以查看已经选了哪些题，可以移除题目，也可以调整题目顺序。

教师可以把不同来源试卷中的题目重新组合成一套新的试卷。

这个功能可以用于制作：

- 复习题
- 小测验
- 周练
- 专题训练
- 错题强化卷
- 考前练习卷

## 13. 新试卷导出

组卷完成后，教师可以把新试卷导出为 PDF。

导出的试卷应该包含：

- 试卷标题
- 题目编号
- 已选题目
- 可选的题型分组标题

导出的 PDF 应该适合打印和发给学生使用。

题目在导出后应该保持清晰，不能明显模糊或变形。

## 14. 保存与继续编辑

系统需要保存教师的处理进度。

教师处理一套 PDF 试卷时，可以中途退出。下次打开时，应该能继续之前的进度。

再次打开一套试卷时，教师希望能看到：

- 原始 PDF
- 已经切好的片段
- 已经删除的无关内容
- 已经合并好的题目
- 已经标注的题型
- 已经填写的章节、知识点和难度

## 15. Windows 安装需求

目前先制作 Windows 版本。

我希望这个系统可以像普通 Windows 软件一样安装和启动。

最好能提供 MSI 这种常见安装包形式。如果实际交付时采用其他 Windows 安装包形式，也应该让用户感觉是正常的软件安装体验。

安装后，用户应该可以从桌面快捷方式或开始菜单打开系统。

## 16. 第一阶段需要完成的功能

第一阶段至少需要完成一条完整流程：

1. 导入 PDF 试卷
2. 查看 PDF 页面
3. 缩放或适应宽度
4. 点击页面横向位置进行裁切
5. 看到裁切线示意和已添加的裁切线
6. 删除不需要的片段
7. 多选片段并合并成一道题
8. 使用题型模板自动标注题型
9. 把题目保存进题库
10. 给题目添加章节、知识点、难度标签
11. 在题库中按题型、来源、章节、知识点、难度筛选
12. 勾选题目重新组卷
13. 调整新试卷中的题目顺序
14. 导出新的 PDF 试卷
15. 再次打开系统后能继续查看和编辑已有内容

## 17. 后续可以考虑的功能

后续可以再考虑更多增强功能。

例如：

- 识别题目文字
- 识别答案和解析
- 自动推荐知识点
- 导入 Word 试卷
- 导出 Word 试卷
- 生成答案卷
- 生成解析卷
- 云同步
- 多设备使用
- 学生端练习
- 错题统计
- 学情分析

这些不是当前第一阶段的重点。

## 18. 成功标准

如果教师能够从一份普通 PDF 物理试卷开始，通过人工裁切和整理，把它变成题库中的一道道题目，再从题库中筛选题目、重新组卷、导出 PDF，那么这个系统的核心需求就成立。

第一阶段最重要的是让这个流程顺畅、清楚、可靠。

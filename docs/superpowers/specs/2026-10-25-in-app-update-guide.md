# M20 软件更新与本机使用说明

目标版本：1.1.0-beta.7。包含 beta.6 的单题识别与校对，并增加应用内版本更新。功能验收由用户执行；类型检查、编译与制作 DMG 不代表更新安装或识别功能已经验收。

## 首次安装与后续更新

beta.6 及更早版本没有软件更新入口。首次安装 beta.7 到 Mac“应用程序”后，从该位置打开“物理教师题库管理系统”。不要长期从 DMG 内运行。

主页、题库浏览、组卷篮及题型模板页顶部提供“软件更新”入口，设置中也有入口。面板可查看当前版本、检查时间、新版说明和下载进度。

1. “启动时检查更新”默认开启，只读取公开仓库的发布信息；不会上传 PDF、题图、密钥或个人题库，也不会自动下载、退出或安装。
2. 点击“检查更新”可立即查询。测试版默认接收测试版；关闭“接收测试版”后只查找正式版，不会退回旧版本。
3. 有新版且存在对应系统安装包时，点击下载。下载过程可取消；下次从头下载。文件校验成功后才出现可安装状态。
4. 保存当前工作后选择安装。Mac 准备新副本、等待正常退出、保留旧应用、替换并重新打开；如果未保存提示中选择继续编辑，本次安装取消。不要在安装准备时继续编辑或开始资料迁移。
5. 网络中断、GitHub 访问限制、校验不符或安装位置不可写时，面板说明原因。可重新检查/下载，或打开 GitHub 发布页获取安装包。

当前 Mac 包针对 Apple Silicon（M 系列）、macOS 13 及以上，未提供 Intel Mac 包。Windows 只有发布了相应 EXE 的版本才可下载，并由常规安装程序完成安装。没有对应包时不会将 Mac 包交给 Windows。

## 数据和恢复

更新替换的是应用文件，保留题库数据库、PDF、题图、答案图、编辑历史、识别候选及本机保存的 Doc2X Key。题库资料仍在原来设置的存储位置，软件更新缓存与题库文件分开。

Mac 更新时，旧应用保存在当前应用同级目录，名称为 `物理教师题库管理系统 - 旧版 <版本> (<随机码>).app`。替换失败会尝试恢复旧应用；旧应用备份只包含程序，不包含题库备份。若新版启动或使用有问题，请保留面板提示及更新目录中的记录并反馈。不要同时运行新旧应用，也不要自行用旧版打开升级后数据库：应用文件恢复不能替代数据格式兼容性判断。当前设置中的“备份数据库”仅备份数据库，不包含全部 PDF 与图片。

当前没有 Apple Developer ID 签名及公证，更新功能不关闭或绕过 macOS 安全检查。受系统权限保护的安装目录需要由用户将应用放到可写的“应用程序”位置，再继续更新。

## Doc2X API Key 申请和配置

1. 打开官方[获取 API Key](https://open.noedgeai.com/login?intent=api)，登录或注册；在控制台的 [API Key 管理](https://open.noedgeai.com/apiKeys)创建 Key。无需把 Key 发到聊天或写进仓库。
2. 打开软件，在“题库浏览”或“组卷篮”找到已入库题目，点击“编辑”。
3. 找到“单题识别与校对”→“识别设置”，填入 API Key，启用 Doc2X 云识别。
4. 需要下次继续使用时，选择用系统安全存储记住新密钥；不选择则只在当前应用会话使用。点击保存设置。
5. 选择识别题干原图或答案原图，核对将上传的图片副本并确认。结果在候选区校对，确认后再采用到正式内容；原件继续保留。

Doc2X API 是收费云服务。2026-10-25 [官方开放平台](https://open.noedgeai.com/)列示按量 ¥0.02/页起、资源包低至 ¥0.01/页；实际按账户额度和官方当前价格结算。开放平台 API 额度与网页版会员不通用。软件检查版本更新不消耗 Doc2X 额度；只有用户确认发起识别才调用该服务。完整识别范围与限制见 [M19 使用说明](2026-10-25-doc2x-ocr-guide.md)。

## 用户自测清单

- [ ] 从“应用程序”打开 beta.7，原题库、原图、编辑内容和设置仍在。
- [ ] 进入软件更新查看当前版本，手动检查可以得到清晰结果。
- [ ] 关闭启动检查后重开应用不会主动查版本；测试版开关可保存。
- [ ] 断网或 GitHub 不可用时有错误提示，题库正常工作不受检查阻塞。
- [ ] 后续发布更高版本后，显示新版说明、正确的 Mac 包和下载进度；取消下载可重试。
- [ ] 安装前未保存的编辑会提示；选择继续编辑时应用留下且不发生延迟替换。
- [ ] 已保存后安装新版本，应用重新打开且资料、原件和识别配置保留。
- [ ] 根据上述步骤配置自己的 Doc2X Key，识别一张题图、校对并采用。

跨版本下载与安装需要未来存在更高版本；本次不能用“已是最新版本”代替这项验收。

## 后续发布约定（维护者）

发布仍沿用 GitHub Releases。先增加 package.json/package-lock.json 版本，完成类型检查及打包，再运行 `npm run release:checksums` 生成同目录的 `SHA256SUMS.txt`。先创建草稿 Release，上传完整安装包、校验文件和交付说明；核对上传完成、文件大小及 GitHub SHA-256 后再公开发布。更新读取已发布 Release，不读取草稿。

Mac 文件名保持 `physics-question-bank-<版本>-mac-<arm64或x64>.dmg`；Windows 保持 `教师题库-测试版-<版本>-安装程序.exe`（x64）。版本标签使用 `v<版本>`，例如 `v1.1.0-beta.8`。同一版本发布后不要替换成不同代码，修复请递增版本。正式版去掉 beta 后缀并取消预发布标记。

参考：[Electron 自动更新与签名要求](https://www.electronjs.org/docs/latest/api/auto-updater)、[GitHub Releases API](https://docs.github.com/en/rest/releases/releases)。

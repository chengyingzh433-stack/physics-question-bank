# M20 应用内更新与 Mac 安装方案

用户已要求软件内检查版本、一键更新安装，并明确授权将 GitHub 仓库公开。仓库已确认公开。本阶段以 1.1.0-beta.6 的完整 Doc2X 功能为基础，交付 1.1.0-beta.7。

## 交付范围

1. 设置中增加“软件更新”：当前版本、检查时间、最新版、更新说明、下载进度、取消下载、安装入口与错误提示。
2. 默认启动后检查一次，可关闭自动检查；测试版默认接收测试版，正式版默认只接收正式版。后台检查不自动下载、不强制安装。
3. 从固定公开 GitHub 仓库读取 Releases，无需 GitHub 账户或令牌。按语义版本比较，正确处理 beta.9 与 beta.10，拒绝降级；选取匹配系统与处理器的安装包。
4. 下载到应用专用缓存，限制来源与大小，并核对发布文件的 SHA-256。取消或失败不影响当前应用，校验不符禁止安装。
5. Mac 点击安装后：校验 DMG 和应用身份、版本，准备新副本；等待正常退出和未保存内容确认后替换应用，保留旧版副本；复制或替换失败恢复旧版，成功后重新打开。数据目录、API Key、题库原件不参与替换。
6. Windows 保持类型、界面和下载兼容；发布含匹配的 NSIS 安装包时交给安装程序继续。没有对应包时明确提示，不错误提供 Mac 包。
7. 制作 beta.7 Apple Silicon DMG，发布 GitHub，安装到本机“应用程序”，旧应用和旧安装包移至废纸篓。用户题库、PDF、图片、编辑内容和密钥不清理。

## 实现依据与边界

- [Electron 官方更新文档](https://www.electronjs.org/docs/latest/api/auto-updater)规定 macOS 内置 Squirrel.Mac 自动更新需要签名。当前没有 Apple Developer ID，因此本阶段采用校验后的 DMG 与 macOS 自带文件工具完成应用替换，不伪称已接入签名自动更新，也不关闭 Gatekeeper。
- [GitHub Releases API](https://docs.github.com/en/rest/releases/releases)支持公开仓库无令牌读取、文件大小及 SHA-256 摘要。固定仓库作为发布来源；公开仓库不是上传题库资料的入口。
- Mac 首先支持从可写目录运行的已安装应用。本机 /Applications 可写；只读磁盘镜像和不可写安装位置给出明确操作提示。不绕过系统权限。
- 对未保存编辑保留现有退出确认。取消退出则取消本次安装；不强制结束进程。安装失败保留可恢复材料。
- beta.6 及更早版本没有本模块，首次由本次安装进入 beta.7；后续发布更高版本后才能由用户实际验收跨版本更新。

## 开发与验收边界

不编写、不运行冒烟测试、自动化功能测试、界面走查脚本或打包应用功能测试。仅做静态代码审查、类型检查、编译、安装包制作和文件级检查，不启动应用进行功能验收。

用户自测：自动检查开关、手动检查、离线提示、测试版开关、版本说明、下载与取消、后续新版本安装、未保存内容阻止退出、更新后题库与 Doc2X 设置保留。交付说明记录实际完成情况及尚待用户验收项目。

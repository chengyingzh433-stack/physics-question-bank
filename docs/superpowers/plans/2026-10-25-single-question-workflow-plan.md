# M22 单题录入、标签与最新题卡

日期：2026-10-25。基于 beta.8，计划交付 beta.9。用户明确优先方便地录入一道题，暂不做批量录题。

## 交付目标

1. 在同一个校对页编辑题干、答案、公式和图片，并选择题型、章节、难度、多个知识点，填写年份和出处。知识点可新建并选中；已有题卡也能进入此页修改标签。
2. 题库卡片及放大预览显示最新保存的编辑内容，无编辑内容时使用原图。答案状态计入已保存的文字答案，避免明明有答案却显示“无答案”。原始 PDF、Word、题图、答案图与历史版本不覆盖。
3. 普通单题图片或截图提供“直接校对”入口；复杂题仍可框选、分区输入与重排。未加入组合的输入文字在继续时自动加入；去掉中间必须确认的预览弹窗，保留可选预览。校对页用一次“保存并入库”同时提交内容和标签，不再要求先保存、再逐部分确认、再确认整题。

## 实现与数据约束

- 复用现有录题草稿、Tiptap、MathLive、Doc2X 候选及标签表，不新增云识别服务、不新增运行依赖。
- 内容和标签在同一数据库事务保存；内容沿用版本冲突检查，标签比对打开时的值，阻止覆盖其他窗口的修改。入库失败时回滚本次内容、标签与发布状态。
- 整题确认只在用户主动勾选“已核对”后生效。云识别仍需明确确认上传；没有 Key 时仍可手工录入。OCR 未保存候选仍需先采用或处理，避免静默丢失。
- 题卡按当前页按需读取编辑稿，不将所有题目的正文一次性载入。正文为空或读取失败时明确显示状态；保留原图查看入口。
- 题卡最新稿与 Word 的“原图/可编辑内容”导出选择分开说明。PDF/PPT 导出仍沿用原图；本阶段不扩大为导出改造或题图重新生成。
- 快捷操作仍生成原图快照并保留原稿；Word 支持 DOCX，复杂版式仍可能需要先转 PDF。

## 检查与交付

不编写、不运行冒烟测试、自动功能测试、界面走查脚本或打包应用功能测试，不调用真实 Doc2X 验收。只做静态审查、类型检查、编译、DMG 制作和文件级核验。

完成使用说明、用户自测清单与交付记录，提交代码并上传 GitHub 预发布 DMG、SHA256SUMS 和说明。更新本机 /Applications 下的软件，旧版移入废纸篓或保留可恢复副本，不修改用户题库、原稿和 API Key。功能与实际使用验收由用户完成。

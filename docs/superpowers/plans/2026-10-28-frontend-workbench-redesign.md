# 前端工作台重构方案

## 本阶段：把单题录入做成顺手的桌面工作台

2026-10-28 使用用户提供的六页物理试卷，在 beta.10 中手工完成了第 1 题的框选、题型选择、保存入库、加入组卷篮和试卷内容预览。此次是真实界面操作，不编写或运行冒烟测试、自动化功能测试或界面走查脚本。仅处理本机文件，没有调用云识别。样题保留在本机，名称带“流程体验”，原有草稿不改动。

发现的问题：原稿被多层标题、说明和按钮挤出首屏；框选后需要滚回顶部找下一步；普通整题录入与分区组题同时展开；校对时原图和图片编辑稿重复占位，标签远在下方；题库两层侧栏挤压题卡；组卷中“可编辑”容易被误解为图片已转成文字。

## 功能结构与操作路径

- 录题：选择文件、粘贴截图/文字、直接输入三个明确入口，未完成草稿放在下方。
- 选题：默认在原稿框选一道完整题，直接进入校对。需要跨页拼接或分别处理选项、配图时打开“分区组题”，保留两种录入方式。多部分草稿继续打开时自动进入分区模式。
- 校对：正文是主区域，题干与答案切换；标签常驻右侧；原图对照按需展开；识别需主动触发。保存入库始终可见。
- 题库：大题卡优先，筛选通过明确按钮打开，仍保留题夹、全部筛选与多选功能。
- 组卷：左侧题序和内容，右侧排版与导出；清楚区分图文稿、仅图片与原图，不声称图片已经识别。

## 视觉与交互

统一深蓝灰文字、低饱和青绿主色、浅灰工作区和白色内容纸面；收窄全局导航，使用简短标题和分级留白。录题工作区固定可视高度，原稿内部滚动，底部动作条保持可见。窄窗口采用上下布局并保留正常滚动。按钮、输入框、空状态、状态标签使用统一尺寸和语义；兼容亮暗主题及键盘焦点。

## 实施边界

复用现有本地文件导入、PDF/DOCX 渲染、框选、组题、编辑、标签、历史版本与恢复逻辑；不迁移数据库，不改原件，不增加批量录题，不自动上传试卷。修复流程中实际暴露的状态与提示问题。保持 macOS / Windows 的快捷键、路径及文件选择兼容。

## 交付与验收

负责静态审查、类型检查、编译、Mac DMG 和本机更新。按本次明确授权手工复核主要流程，不将构建成功称为功能验收通过。功能最终验收仍由用户完成。公开仓库仅提交代码与说明，不提交用户试卷、题图或本机数据库。

用户自测：文件/粘贴/输入三入口；PDF 框选后直接继续；分区文字与配图组合；切换题干/答案与标签；未保存内容离开提醒和恢复；题卡同步；筛选与组卷；Word 中图文与原图导出；窄窗口和暗色主题。

## 完成后再评估下一阶段

优先考虑“同一份原稿连续录题”：保存后直接回到同一 PDF 页、保留页码与缩放、明确下一题选区；仍由教师逐题确认，不做批量自动录题。正式范围以本次重构交付及用户试用反馈为依据。

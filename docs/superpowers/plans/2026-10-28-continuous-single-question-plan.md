# 下一阶段方案：同一份原稿连续录题

状态：待用户审阅，尚未实现。前置交付：beta.11 前端工作台。

## 为什么优先做这个

本次用六页真实物理试卷手工操作后，整题框选、校对、标签与入库已经连通。接下来最影响效率的是：保存后回到首页，继续录同一试卷的下一题时需要再次寻找原稿和位置。无需上批量识别，先把逐题录入的连续性做好。

## 完整操作流程

1. 导入一份 PDF、图片或 DOCX，手工框选一道题。
2. 校对题干、答案与标签，点击“保存并录下一题”或“保存并结束”。
3. 前者保存成功后创建独立新草稿，回到原文件、原页码、原滚动位置与视图缩放；清空上一题选区，防止误录重复内容。
4. 来源和年份可沿用，题型/章节/难度/知识点是否沿用由教师明确选择；答案和题目正文不沿用。
5. 右侧显示本次已保存题目及序号，可以返回修改；退出后从“继续录题”恢复当前草稿与原稿位置。

## 实现细则

- 原稿独立保存，新草稿引用同一原稿，避免反复复制大 PDF；需要确认现有复制草稿的资源所有权与清理规则。
- 为草稿保存视图状态：sourceId、页码、缩放、滚动位置。视图状态与题目正文版本分开，不因移动页面产生正文历史版本。
- “保存并录下一题”必须先确认题目和标签均保存成功，再创建下一草稿；失败时停留原页、保留内容，不能让用户误以为已入库。
- 连点保护和幂等创建：同一次保存最多创建一份下一题草稿。重启恢复不会产生重复题目。
- 分区组题保留跨页与混合图文；新题不继承上题的组成部分和识别候选。
- 未加入的选区、未保存文字与标签均有明确离开提醒。视图恢复不能覆盖已保存的正式内容。
- PDF 视图可精确恢复；DOCX 分页仍可能随渲染变化，需要校验页码边界并给出提示。

## 范围之外

不做整卷自动切题、批量云识别、自动答题和多教师协作。不自动上传原稿。当前 Doc2X 的逐次授权与人工校对要求不变。

## 交付边界与用户验收

继续遵守项目开发准则：实现、静态审查、类型检查、编译和安装包；不编写、不运行冒烟测试或自动化功能测试。此次手工流程体验是用户针对前端重构的单次授权，不作为后续自动测试授权。

用户验收重点：同页连续两题、跨页接下一题、暂存退出恢复、标签沿用开关、保存失败重试、返回上一题修改、PDF/图片/DOCX 各一例。确认后再扩展 OCR 局部文字与配图处理。

# 第二阶段实施方案：同一原稿连续录题

日期：2026-11-15。目标版本：1.1.0-beta.14。状态：实现与静态检查、编译、DMG 制作完成，功能验收由用户完成。

## 范围与操作

保留图片、PDF、DOCX、文字的入口。原稿工作区保存每份原稿的页码、视图缩放和滚动位置，返回与重启后从草稿恢复。选区本身不沿用到下一题。

校对页增加“保存并录下一题”和“保存并结束”。正文、标签、入库状态使用现有同一事务保存；之后另一个事务按上一草稿的唯一接续关系创建下一草稿，重复请求返回同一草稿。后一事务失败明确提示本题已保存，可重试。下一草稿共享原稿引用，正文、答案、选区与识别候选为空。来源、年份默认沿用，题型、章节、难度、知识点分别选择是否沿用；下一题显示实际沿用值。本次录题列表按接续链展示，可查看已录题并回到当前草稿。

数字 PDF 取字使用 PDF.js 已有文字层与当前渲染 viewport，按显示坐标将字符筛选到选区；不再默认为整页。候选弹窗允许校对再采用，采用时追加一个文字部分，保留选区原图与来源。相同选区重复采用会阻止，跨页按采用次序组题，可手工调整顺序。扫描页提示无文字层，不调用 OCR。DOCX 仅提供明确标注的整页文字候选，不声称精确选区取字。

## 数据与失败处理

新增独立视图状态表及前后草稿关联表，不改原稿文件，不生成正文历史噪声。页码越界时限制到有效页并提示。原稿共享来源既有引用表；列表只展示同一接续链。新草稿创建、来源引用、继承标签和接续记录在事务内完成。视图写入失败可见，继续校对前等待写入完成；未加入内容依旧需要暂存。未采用候选不进入正式正文。

## 检查与交付

仅静态代码审查、类型检查、编译、DMG 完整性与安装版本核对。不编写或运行冒烟测试、自动化功能测试、界面走查脚本或打包应用功能测试。更新本机前备份旧应用及数据，发布 GitHub 预发布版本与 DMG。

用户自测：同页连续两题、换页后接续、暂存退出恢复、每项标签沿用开关、重复点击/重试、接续列表返回修改、跨页取字、重复选区、扫描 PDF、旋转 PDF、图片和 DOCX。文字层阅读顺序、公式及局部字宽存在源文件差异，必须对照原图校对；不承诺 OCR 或公式语义还原。

# 整道题录入入口补齐

用户截图已经框住题干、选项与配图，但分区工具只提供“题干”等部分，缺少“整道题”。这是界面语义与实际能力不一致。

本次范围：增加“整道题”作为明确的录入类型，默认选中；完整选区可直接继续校对，不要求拆分或重新输入。分区工具继续支持题干、选项、答案和配图。已加入的内容和未加入的文字仍受现有保护，不用新选区覆盖旧内容。整题图片保持原貌，不自动识别或拆分图中文字。

实现：新增兼容旧草稿的整题组成部分类型；本机组合及编辑稿生成将其作为题目正文。图片、粘贴文字和直接输入入口也使用该类型。旧“题干”类型不迁移、不删除。

检查与交付：静态审查、类型检查、Mac 编译与 DMG 制作；不编写或运行冒烟、自动化功能测试或界面走查脚本。本次不操作用户正在编辑的选区；通过软件更新安装新版本，避免强行关闭丢失当前工作。

用户自测：框选完整题，选择“整道题”，直接继续校对；确认选项和配图保留；已有组成部分和未加入文字不被覆盖；旧草稿仍可继续编辑。新版本写入的整题草稿应使用新版编辑，不建议降级后修改。
